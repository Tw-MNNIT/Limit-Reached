# JOI – Your Personal Intelligence Companion

> An AI-powered personal companion designed to understand you, remember what matters, and organize your knowledge over time.

## About the Project

JOI is a personal AI companion that aims to go beyond traditional question-answering chatbots. It is designed to maintain useful context about a user's interests, preferences, activities, and conversations, making interactions more personalized and meaningful.

A central part of JOI is its **Memory Bank**, where information can be organized into customizable folders based on different aspects of a user's life.

## Core Concept

- **Personalized AI Companion:** An assistant that adapts its responses using relevant user context.
- **Memory Bank:** A structured space to store and retrieve useful information.
- **Custom Memory Folders:** Create and organize folders for academics, subjects, hobbies, friends, music recommendations, and more.
- **Memory Management:** Users can create and delete their own memory folders.
- **Contextual Recall:** Retrieve previously stored information when it becomes relevant to a conversation.

## Vision

To build an AI companion that doesn't just answer questions but gradually becomes more useful by understanding the user's context, preserving meaningful information, and making knowledge accessible whenever needed.
